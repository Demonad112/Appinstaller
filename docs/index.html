Appinstaller

Generates a single .cmd file for Windows that silently sets up the items you tick below. No wizard, no click-through, and no admin account required unless an item is marked otherwise.

Everything below runs in your browser. Nothing you type or upload here is sent to a server — the file is generated locally and only exists on your computer.

Before you send it

  

    
One security prompt is unavoidable. Windows marks any script downloaded
    from the internet or email with "Mark of the Web." Double-clicking it will show one
    "The publisher could not be verified. Are you sure you want to run this?" dialog.
    That's normal — a .cmd file can't be signed the way a real installer can.
    To avoid it entirely: copy the file over by USB, or right-click it → Properties →
    check "Unblock" before sending it, or run it yourself over a remote session.

    
uBlock Origin Lite installs in "Basic" mode. Full uBlock Origin was
    removed from the Chrome Web Store in 2026 when Chrome dropped Manifest V2 entirely, so
    Chrome's replacement extension is used instead. Basic mode blocks ads and trackers via
    static network rules with no configuration needed. Chrome has no policy to pre-grant the
    broader permissions "Optimal" mode needs — that's a one-time, 3-click upgrade
    (extension icon → mode slider → grant permission) you can do yourself during
    handoff if Basic isn't blocking enough for a particular site.

    
After install, Chrome's menu will show "Managed by your organization." That's expected
    and only refers to this one extension policy — it is not a sign anything else changed.

  


  
Moving Chrome bookmarks

  

    
On the old computer, run Capture-Profile.cmd
    while signed in to the Windows account that uses Chrome. It saves each Chrome profile's
    bookmarks to the Desktop as Bookmarks-*.json. Choose one in the "Chrome
    bookmarks" step above. Only bookmarks move: never passwords, cookies, history or sign-in.
